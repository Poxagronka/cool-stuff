# Telegram — правила

**R1.** Bot API не отдаёт историю. Обновления живут 24 часа, и прочитать
сообщения, отправленные до появления бота, невозможно никаким способом.
История берётся только через MTProto (Telethon) от имени пользователя.

**R2.** Privacy mode у бота отключается ДО добавления в группу. Настройка
применяется в момент добавления, так что смена порядка означает молчащего
бота: `/setprivacy` → Disable → только потом добавлять.

**R3.** Один токен — один webhook. Переиспользовать токен другого бота
(например `abooks_bot`) нельзя: `setWebhook` перебьёт чужой URL.

**R4.** Ссылки `t.me/c/<id>/<msg>` существуют только для супергрупп и каналов,
у которых id начинается с `-100`. У обычной группы такой ссылки нет вообще —
собирать её из id без префикса значит класть битый url в каждую заметку.

**R5.** Telegram помечает ссылкой и голый хост без схемы (`butkus.org`).
Схему надо достроить до разбора url, иначе `urlsplit` прочитает хост как путь
и домен выйдет пустым.

**R6.** Смещения в `entities` считаются в единицах UTF-16, а не в символах
Python. С эмодзи и не-BMP символами наивная нарезка по индексам ломается.

**R7.** Файл `.session` создаётся при первой же попытке входа, даже
неудачной. Его наличие не значит, что вход выполнен — спрашивать
`client.is_user_authorized()`.
